# ☕ Tim Hortons Coffee Run App

A SwiftUI iOS application inspired by daily team coffee runs at Tim Hortons.  
This app allows team members to save and manage coffee orders instead of writing them down on paper.

# 📱 Features

- Add coffee orders
- Save customer names
- Select drink sizes
- Add special notes
- Store and display orders
- Coffee Run Timer
- Tim Hortons inspired red and brown theme
- SwiftUI navigation and forms
- ObservableObject state management

# 🚀 How to Run

1. Open the project in Xcode
2. Select an iPhone Simulator
3. Press the Run ▶ button
4. Add and manage coffee orders
